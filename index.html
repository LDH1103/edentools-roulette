저장된 채널

    같이 쓰는 목록이라 지우면 모두에게서 사라집니다. 삭제를 한 번 더 눌러야 지워집니다.

    새 채널 추가

    Webhook 주소 만드는 법
    1. api.slack.com/apps 에서 Create New App → From scratch로 앱을 만듭니다.
    2. 왼쪽 메뉴 Incoming Webhooks에서 Activate Incoming Webhooks를 켭니다.
    3. Add New Webhook to Workspace를 누르고 채널을 고른 뒤 허용합니다. 회사 워크스페이스는 관리자 승인이 필요할 수 있습니다.
    4. 생긴 주소 옆 Copy를 눌러 아래 칸에 붙여 넣습니다.
    알림 목록에 보일 이름입니다. Slack 채널 이름과 같게 적으면 헷갈리지 않습니다.
    Slack 에서 복사한 주소를 그대로 붙여 넣으세요.

    채널 목록은 서버에 저장되어 같이 씁니다. 주소는 서버에만 보관하고 화면에는 채널 이름만 보입니다.
