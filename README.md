# 구슬 레이스

링크 하나로 모두가 **같은** 구슬 레이스를 보는 추첨기입니다. Slack 채널에 링크만 올리면 화면공유 없이 함께 볼 수 있습니다.

- 사이트: https://roulette.edentools.dev
- 동기화 서버: https://roulette-api.edentools.dev (Cloudflare Worker + Durable Object, `worker/`)

[Marble Roulette](https://github.com/lazygyu/roulette) by lazygyu 를 바탕으로 만들었습니다 (소스 코드 MIT). 원작의 이름 "마블 룰렛"/"Marble Roulette" 은 원작자의 상표이므로 쓰지 않습니다.

## 사용법

1. 사이트를 열고 참가자를 입력합니다. 자주 쓰는 이름은 "명단 편집"으로 저장해 두면 다음부터 칩을 클릭해 고를 수 있습니다.
2. 맵, 스킬, 당첨 방식(앞에서 N명 / 뒤에서 N명 / 등수 범위)을 정하고 **공유 링크 만들기**를 누릅니다.
3. 화면 왼쪽 아래 카드에 나온 링크(또는 "Slack 안내 문구 복사")를 채널에 올립니다. 보는 사람은 링크를 열어 두기만 하면 됩니다. 보는 사람 화면에는 버튼이 없고, 조작은 링크를 만든 사람만 합니다.
4. 주최자가 **시작**을 누르면 3초 카운트다운 뒤 모든 화면에서 동시에 출발합니다. 늦게 들어온 사람도 현재 시점까지 빠르게 따라잡습니다.
5. 결과가 나오면 주최자는 **다시 추첨**(같은 설정, 새 시드)이나 **설정 수정**(참가자·맵·당첨 방식 변경)으로 같은 링크에서 다시 돌릴 수 있습니다. 설정 수정은 시작 전 대기 중에도 됩니다. 카운트다운 중에는 **다시 추첨**으로 출발을 멈출 수 있습니다.

방 없이 바로 돌려보려면 **혼자 돌리기**를 누르면 됩니다.

### Slack 알림

1. Slack 에서 앱을 만들고 **Incoming Webhooks** 를 켠 뒤 채널을 골라 Webhook 주소를 받습니다 ([안내](https://api.slack.com/messaging/webhooks)).
2. 설정의 **알림 → 추가** 창에 채널 이름과 주소를 넣고, **테스트 보내기**로 채널에 확인 메시지가 오는지 본 뒤 저장합니다. 주소는 이 브라우저에만 저장되고, 추첨마다 채널을 고를 수 있습니다.
3. 채널을 고르고 링크를 만들면:
   - 주최자 카드의 **#채널에 보내기** 로 추첨 링크를 올립니다.
   - **시작**을 누르면 출발 알림이 자동으로 갑니다.
   - 결과가 나오면 주최자 화면이 결과를 캡처해 당첨자와 함께 올립니다. 주최자 탭이 숨어 있어도 레이스는 끝까지 진행됩니다. 탭을 닫으면 결과 알림은 가지 않습니다.

Webhook 주소는 서버에만 보관하고 보는 사람에게 보내지 않습니다. 결과 이미지는 방과 함께 마지막 활동 뒤 30일 동안 보관합니다.

## 원작과 다른 점

- **빠른 확정**: 당첨 범위가 맨 뒤까지면(뒤에서 N명, 끝 등수까지의 범위) 앞사람이 모두 들어와 범위 인원만 남는 순간 결과를 냅니다. 남은 사람끼리의 순서는 없으므로 결과에 ☆(공동)로 표시합니다.
- **결정론**: 시드 난수(`src/utils/rng.ts`)로 구슬 배치·밀도·스킬·흔들기를 정하고, 물리 틱(10ms)마다 슬로모션 비율·순위 정렬·골인 제거를 처리해 프레임 속도와 무관하게 같은 결과가 나옵니다. Box2D wasm 은 비SIMD 빌드 하나로 고정합니다.
- **동시 시작**: 서버 시각 기준 시작 시각을 받아 모두 같은 틱을 봅니다 (`src/sync.ts`, `worker/`). WebSocket 이 막힌 환경에서는 1.5초 간격 HTTP 조회로 같은 상태를 받고, 시작·다시 추첨은 항상 HTTP 로 보냅니다.
- 광고, 상점, 맵 공유마당, 키워드 스프라이트, 분석, 서비스워커는 뺐습니다. 원작의 특정 인물 이미지도 넣지 않습니다.

## 개발

```bash
yarn            # 의존성 설치 (corepack yarn)
yarn dev        # http://localhost:1235  (동기화 서버는 http://localhost:8787 을 본다)
yarn build      # dist/
```

동기화 서버:

```bash
cd worker
npx wrangler dev        # 로컬
npx wrangler deploy     # 배포 (Cloudflare 로그인 필요)
```

`main` 에 push 하면 GitHub Actions 가 빌드해 GitHub Pages 로 배포합니다 (`.github/workflows/deploy.yml`).
